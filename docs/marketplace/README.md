# Marketplace media

Source files for the [JetBrains Marketplace listing](https://plugins.jetbrains.com/plugin/34594-cranpose),
captured from Cranpose Studio 0.13.3 in RustRover on 28 September 2026.

## Screenshots on the listing

| File | Shows | Size |
| --- | --- | --- |
| `01-rust-preview.jpg` | Rust composables beside the running native Showcase preview | 3302 × 1862 |
| `02-layout-inspector.jpg` | Selected component, layout tree, bounds and source details | 3302 × 1862 |
| `03-live-number-controls.jpg` | Numeric slider with configurable range and step, after updating source | 800 × 760 |

Marketplace accepted all three. The third is narrower than its recommended
1200 pixels. The Studio panel and live-value popups were redesigned in 0.14.0,
so replacement captures should come from 0.14 or later.

## Demo video

`cranpose-studio-demo.mp4` is a 31-second, 1920 × 1080 H.264 video without
audio. It shows the native preview, numeric slider editing, editor Undo and
layout inspection, recorded from real UI interaction with pauses between scenes
removed. It is a demonstration, not a latency benchmark.

The listing's video field takes a YouTube URL. This video has not been uploaded
to YouTube or embedded on the listing.
